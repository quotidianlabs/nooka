# nooka 1.4.0

Recurring tasks, without the detour. 1.3.0 added tasks that come back on their
own — but you had to create a task first and then open Edit to make it repeat.
This release puts **Repeat right in the add dialog**, and makes the repeat
controls comfortable to use.

## Highlights

- **Set Repeat while adding.** The quick-add dialog now has the same Repeat
  switch as Edit: turn it on, pick every N **days**, **weeks**, or **months**,
  and the task is recurring from the start. Adding several tasks in a row?
  Repeat switches off again after each add — it never silently sticks to the
  next task you type, while your chosen category still carries over.
- **Bigger, easier-to-tap controls.** The repeat stepper and unit selector are
  now full-width rows with comfortably large touch targets, in both the add
  and edit dialogs — no more hunting for tiny − / + buttons.
- **Fits small phones.** With the keyboard open and Repeat expanded, the
  dialogs now scroll instead of overflowing on compact screens (fixed for
  iPhone SE-class sizes and alike).
- **More natural wording.** Intervals read like a person wrote them — "every
  day" instead of "every 1 days", and a task due back today says "Returns
  today" ("Вернётся сегодня") instead of "in 0 days". In both English and
  Russian.

Nothing changes for existing tasks or backups — no data migration in this
release.
