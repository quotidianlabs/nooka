# nooka 1.2.2

nooka is now available on **RuStore**, VK's Russian Android store, alongside the
existing sideload APK. This release has no functional changes from 1.2.1 — it
establishes the app on RuStore with a fresh version code.

## Notes

- **Get it on RuStore:**
  <https://www.rustore.ru/catalog/app/io.github.quotidianlabs.nooka>
- **Google Drive backup** needs Google Play Services. On RuStore devices without
  it, connecting Drive fails to a localized error; the local file export/import
  works everywhere.

Install from RuStore, or sideload the attached `nooka-1.2.2.apk` on Android.
